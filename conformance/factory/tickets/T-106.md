## Description

Give operators one documented, non-task command that checks the configured
Codex, Claude Code, Cursor OpenAI, and Cursor Anthropic adapters before a
ticket starts. The check must make startup-only fallback readiness visible
without submitting a task to any model.

## Acceptance criteria

1. One documented command or script reports readiness for all four configured
   adapters and identifies each adapter's provider family.
2. The check distinguishes disabled optional fallback from invalid or
   unavailable configuration and exits nonzero when no safe route exists.
3. Automated tests prove that readiness checks never submit task content.
4. Operator guidance states that fallback selection happens only before task
   submission and is never a post-failure retry.
