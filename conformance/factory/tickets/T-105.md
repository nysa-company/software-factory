## Description

3. Linear priority, Project membership, Ready, approval, and valid unblock transitions reconcile into Markdown; unsupported state edits are restored from Markdown.
4. Contracts, verdicts, logs, evidence bundles, and cost remain Git-owned and continue to drive local preflight and sequencing without a live Linear request.
5. A shared Project-filtered factory pipeline view surfaces this initiative's issues with their current workflow states.
6. Mocked GraphQL, sequencer, preflight, conformance, and immutability suites pass.
